# Daily Tracker — Motivation research (non-normative)

**This document is design inspiration only.** It must not drive UI copy or product voice. Normative rules live in [PRODUCT.md](./PRODUCT.md).

Guild Wars 2 (achievements, Wizard’s Vault, legendary / mount journeys) is studied for *mechanics* that keep ambitious work moving — not to build a game tracker.

## Why GW2’s achievement panel works

1. **Visible, tiered progress** — bars show the *next* milestone, not only done/not done.
2. **Meta achievements** — big goals complete when child achievements complete; small steps feed meaning.
3. **Bits / checklists** — discrete next actions; always clear what to do next.
4. **Watch list + nearly complete** — pin active pursuits; surface almost-done items (high ROI).
5. **Instant celebration** — feedback on the step, not only the finish line.
6. **Fixed point economy** — AP / Astral Acclaim are standardized; players don’t invent scoring.
7. **Daily / weekly “enough”** — Wizard’s Vault rewards thresholds, not 100% of every objective; weeklies carry more weight than dailies.
8. **Soft time pressure** — miss a day = no currency that day, not permanent loss of progress.

## Legendary / long-ambition journeys

Griffon, Skyscale, and legendary weapon tracks show how multi-week work stays motivating when the end item looks like “just a skin”:

1. **The journey is the product** — themed chapters, not a flat mat dump; end state = identity + new capability.
2. **Chaptered collections** — Acts with their own finish lines beat flat 80-item lists.
3. **Taste before earn** — temporary previews of the end state mid-journey.
4. **Intermediate milestones** — hold a worse→better version of the prize along the way.
5. **Checklist permanence** — completed bits stay checked; progress is undeniable.
6. **Parallel lanes** — any session can advance *something*.
7. **Soft care gates** — miss slows; does not ruin the arc.
8. **After unlock** — mastery / follow-on so finishing isn’t a cliff.

## Market lessons (what not to copy)

| Source of failure | Lesson |
|-------------------|--------|
| Habitica HP / party dependency | Solo users need mastery without punishment spirals |
| LifeUp-class DIY shops | User-priced rewards inflate and collapse meaning |
| Todoist Karma quantity | Points-per-checkmark → busywork farming |
| Streaks-as-product | One miss → shame → abandon; prefer soft streak / strength |
| Notion / Marvin setup theater | Capture must stay cheaper than thought |
| Jira / Trello / ADO for solo | Coordination primitives without a second person |

## Mechanics we steal (mapped to PRODUCT.md)

| GW2 mechanic | Daily Tracker mechanic |
|--------------|------------------------|
| Achievement → tiers → bits | Epic → Act → Story |
| Next-tier bar + next objective | Act% + overall% + next Story on Today |
| Wizard’s Vault N-of-M | Fixed daily/weekly Period bonuses |
| Soft miss | No wipe of best streak / completed Stories |
| Legendary chapters + preview | Legendary flag, Act deliverables, mid-journey preview |
| Fixed AP / chests | Fixed Gold/Silver/Bronze + fixed Act/Epic grants |
