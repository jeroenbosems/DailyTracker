# Motivation design notes (non-normative)

Research inspiration for *mechanics*. **Not** UI copy. **Not** requirements — see REQUIREMENTS.md.

## What we steal (structure)

- Layered goals: months / weeks / days (Epic / Phase / Step)
- Always-visible next step + progress in current phase + overall
- Intermediate finish lines and early “preview” of the end state
- Soft miss (slow, don’t wipe); N-of-M “enough” period bonuses
- Fixed reward economy biased to high-priority / needed work
- Parallel steps inside a phase so a session can always advance something

## What we refuse

- Habitica-style HP punishment / guilt spirals
- DIY point shops that inflate
- Quantity-Karma busywork farming
- Team-tool ceremony for an audience of one
- Game chrome replacing clarity

## Primary references

- GW2 achievements / collections / legendary journeys / Wizard’s Vault (design analysis)
- Competitive: Habitica, Loop, Todoist Karma, Notion fatigue, Jira-for-solo failure modes

Product framing remains: **personal productivity for ambitious solo targets.**
