# Weekly review (v0.9)

Read-only `/review` for the current ISO week:

- Completed Tasks, Routines (by last_completed_on), and Steps
- Active Epic progress % and next Step
- Points earned (sum of reward_logs this week)
- Daily / weekly Period bonus status

Entry: nav **Review** + Today footer link. Single CTA: **Back to Today**. No email or push.
